# 🪨 Animated Caveman 404 Page

A creative and fun **404 Error Page** featuring an animated caveman, built using only **HTML and CSS**. This project adds personality and humor to your website when users land on a missing page.

---

## 🚀 Features

* 🎨 Pure HTML & CSS (No JavaScript)
* 🧍 Animated Caveman Character
* 💫 Smooth CSS Animations
* 📱 Responsive Design
* 😄 Engaging 404 User Experience
